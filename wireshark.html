Wireshark — Packet Analyzer

Wireshark is a free, open-source network protocol analyzer that captures and lets you inspect every packet traveling across a network interface in real time. It's one of the most widely used tools in both security research and network troubleshooting, trusted by professionals worldwide.

// What Is a Packet?

Think of a packet like a physical letter traveling through the postal system. The envelope has a "from" address (source IP) and a "to" address (destination IP), and inside the envelope is the actual content — the payload. Network communication works the same way: data is broken into small chunks called packets, each with header information describing where it came from and where it's going, plus the actual data being sent. Wireshark lets you open every envelope and read every letter passing through your network interface — in real time, as they travel.

// What Wireshark Reveals

Wireshark captures traffic as a GUI application — you see a live feed of packets with protocol, source, destination, and payload data. During a security test, Wireshark can expose: unencrypted credentials in HTTP login forms, DNS queries that reveal internal hostnames and network structure, ARP traffic mapping physical MAC addresses to IP addresses, and any data transmitted without encryption. The core insight is simple: anything unencrypted is readable by anyone watching the wire.

// Real-World Example: HTTP Login Capture

Imagine a user on the same network submits a login form to a site running plain HTTP instead of HTTPS. Wireshark captures the full TCP conversation — including the raw POST request body. Below is what that exchange looks like in a packet capture:

# Source Destination Protocol Info
1 192.168.1.55 203.0.113.10 TCP SYN → port 80
2 203.0.113.10 192.168.1.55 TCP SYN-ACK
3 192.168.1.55 203.0.113.10 HTTP POST /login.php HTTP/1.1
↳ Payload: username=admin&password=hunter2  [PLAIN TEXT — FULLY VISIBLE]
4 203.0.113.10 192.168.1.55 HTTP HTTP/1.1 302 Found → /dashboard

In a real penetration test, this would be documented as a critical finding: "Credentials transmitted over unencrypted HTTP. Intercepted via passive network capture with no active attack required. Remediation: enforce HTTPS site-wide using TLS 1.2 or higher. Implement HSTS headers."

⚠ LEGAL BOUNDARY

Capturing network traffic you don't own or don't have authorization to monitor is illegal under the Electronic Communications Privacy Act (ECPA). Wireshark is a legitimate diagnostic and security tool — on networks where you have explicit permission. Passive sniffing on a network without written consent is federal wire-tapping, regardless of whether you intended to do anything with the data.
